# B2B-program-doodle
# B2B程序涂鸦 · B2B销售项目管理工作台

面向 B2B 销售与项目管理的轻量级 Web 工作台：客户管理、销售机会看板（支持拖拽）、项目看板、任务中心、时间筛选与月度对比、销售分析图表。

## 技术说明
- 纯前端单文件应用（HTML + CSS + 原生 JS），无后端依赖
- 图表使用 ECharts CDN
- 数据为前端示例数据，存于页面 DB 对象中

浏览器直接打开 index.html 即可
