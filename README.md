# SalesFlow · B2B 销售项目管理工作台

轻量级的前端工作台，用于统一管理客户、销售机会、项目与任务。界面简洁、功能聚焦，适合作为内部销售/交付团队的演示与轻量日常管理工具。

演示（GitHub Pages）：https://Sunty.github.io/B2B-program-doodle/

## 主要功能
- 客户管理：客户档案、联系人、行业与状态流转（重点/跟进/项目/暂缓/已成交/流失）。
- 销售机会（看板）：五阶段看板（线索 → 需求确认 → 方案报价 → 商务谈判 → 成交），支持拖拽调整阶段。
- 项目看板：待启动 / 进行中 / 验收中 / 已完成，支持进度追踪。
- 任务中心：任务创建、负责人、截止时间与状态管理。
- 跟进记录：记录每次沟通与下一步行动。
- 时间筛选与时间锚点对比：支持全部 / 近7天 / 本月 / 近30天，并自动计算“本月 vs 上月”的指标变化。
- 销售分析：ECharts 可视化（销售漏斗、月度趋势、客户行业分布、阶段平均金额）。

## 技术说明
- 纯前端单文件应用（`index.html`）：HTML + CSS + 原生 JavaScript，无后端依赖。
- 图表使用 ECharts（通过 jsDelivr CDN 加载）。
- 示例数据以内置 `DB` 对象提供，可直接替换为真实数据或改造为 API 调用。

## 本地运行
1. 克隆仓库或下载文件。
2. 用浏览器直接打开 `index.html` 即可（无需安装依赖）。

## 部署到 GitHub Pages（推荐）
1. 在仓库中确保 `index.html` 和 `README.md` 在根目录。
2. 打开仓库页面 → Settings → Pages。
3. 在 "Source"（来源）中选择分支（例如 `main`）和目录 `/ (root)`，保存。
4. 1–2 分钟后，页面将通过 `https://<你的用户名>.github.io/<仓库名>/` 访问（若使用 GitHub 用户名 `Sunty`，则地址为示例顶部的演示链接）。

如果想使用 `docs/` 目录部署，可将 `index.html` 移到 `docs/index.html`，并在 Pages 设置中选择 `docs/`。
